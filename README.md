# System Foundry

System Foundry는 하루에 두 개의 수익형 소프트웨어 MVP를 자동으로 설계하고, 구현하고, 테스트하고, 문서화하는 프로젝트입니다.

## 목표

- 매일 오전 9시와 오후 4시에 프로젝트 1개씩 생성
- 실제 고객 문제를 해결하는 소형 수익형 시스템 개발
- 프로그램 본체, 테스트, 실행 문서, PDF 보고서 자동 생성
- 검증된 결과물을 GitHub에 자동 업로드
- 우수 프로젝트를 별도 제품으로 발전

## 기본 파이프라인

```text
아이디어 선정
→ 요구사항 정의
→ 프로그램 생성
→ 자동 테스트
→ 실행 화면 기록
→ PDF 보고서 생성
→ GitHub 업로드
```

## 프로젝트 결과물

각 프로젝트는 다음 구조를 기본으로 합니다.

```text
projects/YYYY/MM/YYYY-MM-DD-HHMM-slug/
├── app/
├── tests/
├── screenshots/
├── README.md
├── report.pdf
├── project.json
├── .env.example
├── .gitignore
├── Dockerfile
└── logs/build.log
```

## 운영 원칙

- 핵심 기능은 1~3개로 제한합니다.
- 실제로 실행하고 테스트한 결과만 성공으로 기록합니다.
- API 키와 개인정보는 저장소에 업로드하지 않습니다.
- 생성된 프로젝트는 기본적으로 비공개 상태에서 검토합니다.
- 공개 전환, 강제 푸시, 기존 프로젝트 삭제는 자동으로 수행하지 않습니다.

## 상태

현재 System Foundry 자동화 파이프라인을 설계하고 있습니다.
