# ShiftSeal

교대 인수인계의 마감 업무와 미해결 이슈를 우선순위로 관리하는 로컬 우선 웹 시스템입니다.

## 대상 고객과 가격

- 대상: 2~15인이 교대 근무하는 소형 카페·소매점·예약형 매장
- 가격: 사업장당 월 ₩15,000

## 핵심 기능

1. 구역·업무·담당자·완료시각·중요도를 검증해 등록
2. 시간 초과와 중요도 기반 인수인계 큐
3. 미완료 수와 교대 완료율 대시보드

데이터는 브라우저 `localStorage`에만 저장되며 외부로 전송되지 않습니다.

## 설치·테스트·실행

Node.js 20 이상과 Python 3이 필요합니다.

```bash
npm install
npm test
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## Docker

```bash
docker build -t shiftseal .
docker run --rm -p 4173:4173 shiftseal
```

## 보안 및 제한사항

- 고객 개인정보, 비밀번호, 결제정보를 입력하지 마세요.
- 브라우저 데이터를 지우면 기록도 삭제됩니다.
- 다중 사용자 동기화, 로그인, 알림, 감사 로그는 MVP에 포함하지 않습니다.
- 내부 체크리스트이며 안전·노무·회계 규정을 대신하지 않습니다.
