# PickupDesk

소형 전자기기·자전거·생활용품 수리점이 수리 완료 물품의 수령 약속일, 미수금, 보관료와 대기 상태를 관리하는 로컬 우선 업무 도구입니다.

## 핵심 기능

1. 접수번호·고객 별칭·완료일·수령 약속일·미수금 검증 등록
2. 약속 경과·오늘 수령·곧 수령 순의 연락 큐
3. 미수금과 3일 이후 보관료, 수령 완료 상태 집계

## 설치 및 실행

Node.js 20 이상과 Python 3가 필요하며 외부 런타임 의존성은 없습니다.

```bash
npm install --ignore-scripts
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 데이터는 해당 브라우저의 `localStorage`에만 저장됩니다.

## 사용 방법

- 수리 완료 시 고객 이름 대신 별칭과 물품, 수령 약속일, 미수금을 등록합니다.
- 수령 연락 큐 위에서부터 약속 경과 고객에게 연락합니다.
- 물품 인계와 결제가 끝나면 `수령 완료`를 누릅니다.

## 보안 및 제한사항

- 서버, 계정, 외부 API, 분석 도구를 사용하지 않습니다.
- 연락처나 주소를 저장하지 않고 사용자 입력을 검증·이스케이프합니다.
- 보관료는 영업일이 아닌 달력일 기준의 단순 추정값입니다. 실제 청구 전 사업자의 고지·동의·지역 법규를 확인해야 합니다.
- 여러 기기·직원 간 동기화와 자동 문자 발송은 포함하지 않습니다.
