# BoxBridge

이사 상자별 내용물과 도착 방을 기록하고 검색하며, 포장 해제 진행률을 관리하는 로컬 우선 웹 도구입니다.

## 대상 고객과 가격

- 대상: 원룸·아파트 이사를 직접 준비하는 개인과 소형 가구
- 가격: 1회 구매 ₩8,900

## 핵심 기능

1. 상자 코드·도착 방·내용물·깨짐주의 여부를 검증해 등록
2. 코드·방·내용물 통합 검색
3. 포장 해제 상태와 전체 정리 진행률 추적

데이터는 브라우저 `localStorage`에만 저장되며 외부로 전송되지 않습니다.

## 설치·테스트·실행

Node.js 18 이상과 Python 3이 필요합니다.

```bash
npm install
npm test
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## Docker

```bash
docker build -t boxbridge .
docker run --rm -p 4173:4173 boxbridge
```

## 보안 및 제한사항

- 현금, 신분증, 비밀번호, 귀중품의 구체적 위치를 입력하지 마세요.
- 브라우저 데이터를 지우면 기록도 삭제됩니다.
- 사진 첨부, 기기 간 동기화, 공동 편집, 라벨 인쇄는 MVP에 포함하지 않습니다.
