# FridgeFirst

냉장고 식품을 소비기한 순으로 정리하고, 3일 안에 먼저 쓸 식품의 금액과 사용·폐기 결과를 기록하는 로컬 우선 개인용 웹 도구입니다.

## 핵심 기능

1. 식품명·수량·구매가·소비기한 검증 및 등록
2. 기한별 소비 우선순위와 3일 내 낭비 위험 금액 계산
3. 사용 완료·폐기 기록과 절약·낭비 금액 집계

## 설치 및 실행

Node.js 20 이상과 Python 3가 필요하며 런타임 의존성은 없습니다.

```bash
npm install --ignore-scripts
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 데이터는 해당 브라우저의 `localStorage`에만 저장됩니다.

## 사용 방법

- 장을 본 뒤 식품명, 분류, 소비기한, 수량, 단위, 구매가를 등록합니다.
- `소비 우선순위`에서 오늘 또는 3일 안에 사용할 식품을 먼저 확인합니다.
- 실제 사용 후 `사용 완료`, 버린 경우 `폐기 기록`을 선택합니다.
- 상단에서 낭비 위험 금액과 사용 완료 금액을 비교합니다.

## 보안과 개인정보

- 외부 API, 분석 도구, 서버 데이터베이스를 사용하지 않습니다.
- 입력 길이·숫자 범위·날짜·분류 값을 검증합니다.
- 화면에 표시하는 사용자 입력은 HTML 특수문자를 이스케이프합니다.
- `.env`, API 키, 계정 정보가 필요하지 않습니다.

## 가격 모델

- 개인용 로컬 라이선스: 1회 ₩8,900
- 대상: 1~2인 가구, 자취생, 식재료를 자주 남기는 개인

## 안전 및 제한사항

표시 기한과 우선순위는 정리 보조 정보이며 식품 안전을 보장하지 않습니다. 보관 상태와 냄새·외관이 의심되거나 기한이 지났다면 섭취하지 마세요. 단일 브라우저 MVP라서 저장소를 지우면 기록이 사라지며, 바코드 인식과 기기 간 동기화는 지원하지 않습니다.
