# ScopeSeal

소형 디자인·영상·웹 스튜디오가 메신저에 흩어진 수정 요청을 기록하고, 계약상 포함 횟수와 추가 청구액을 계산하며, 승인 상태를 추적하는 로컬 우선 업무 시스템입니다.

## 핵심 기능

1. 프로젝트 계약 기준과 수정 요청 검증·등록
2. 포함 수정 잔여 횟수, 범위 초과 여부, 예상 추가 청구액 자동 계산
3. 검토 전·견적 전달·승인·완료 상태 추적

## 설치 및 실행

Node.js 20 이상과 Python 3가 필요하며 런타임 의존성은 없습니다.

```bash
npm install --ignore-scripts
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 모든 프로젝트 데이터는 해당 브라우저의 `localStorage`에만 저장됩니다.

## 사용 방법

- `계약 기준 설정`에서 프로젝트명, 고객 별칭, 포함 수정 횟수, 시간당 단가를 입력합니다.
- 새 요청이 원계약 범위에 속하는지 선택하고 예상 작업시간을 등록합니다.
- 범위 내 요청은 남은 포함 횟수를 사용하고, 범위 밖이거나 횟수를 초과하면 추가 청구액을 계산합니다.
- 견적 전달과 고객 승인 여부를 상태로 갱신합니다.

## 보안 및 개인정보

- 외부 API, 분석 도구, 서버 데이터베이스를 사용하지 않습니다.
- 고객 실명 대신 별칭 사용을 권장합니다.
- 입력 길이·숫자 범위·0.5시간 단위·날짜·상태 값을 검증합니다.
- 사용자 입력을 화면에 출력할 때 HTML 특수문자를 이스케이프합니다.
- `.env`, API 키, 관리자 계정이 필요하지 않습니다.

## 가격 모델

- 셀프호스팅 1개 스튜디오: 월 ₩24,000
- 대상: 2~10인 디자인·영상·웹 제작 스튜디오와 프리랜서 팀

## 제한사항

단일 브라우저 MVP입니다. 고객 전자승인 링크, PDF 변경 견적서, 팀 계정, 회계 도구 연동은 후속 버전 범위입니다. 실제 청구 전에는 계약서와 고객 합의를 다시 확인해야 합니다.
