# BatchBalance

생산 배치의 계획 수량, 완제품, 폐기량을 기록해 수율과 폐기 비용을 보여 주는 로컬 우선 웹 시스템입니다.

## 대상 고객과 가격

- 대상: 배치 생산 원가와 폐기량을 관리하는 소형 베이커리·디저트 공방
- 가격: 사업장당 월 ₩17,000

## 핵심 기능

1. 제품·배치·계획량·완제품·폐기량·원가를 검증해 등록
2. 배치별 수율, 미분류 수량, 폐기 비용 자동 계산
3. 낮은 수율을 우선 표시하는 손실 위험 큐와 요약 대시보드

데이터는 브라우저 `localStorage`에만 저장되며 외부로 전송되지 않습니다.

## 설치·테스트·실행

Node.js 18 이상과 Python 3이 필요합니다.

```bash
npm install
npm test
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## Docker

```bash
docker build -t batchbalance .
docker run --rm -p 4173:4173 batchbalance
```

## 보안 및 제한사항

- 고객 개인정보, 비밀번호, 결제정보를 입력하지 마세요.
- 브라우저 데이터를 지우면 기록도 삭제됩니다.
- 다중 사용자 동기화, 로그인, 알림, 감사 로그는 MVP에 포함하지 않습니다.
