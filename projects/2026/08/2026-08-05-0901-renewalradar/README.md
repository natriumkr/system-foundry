# RenewalRadar

개인 구독 서비스의 다음 갱신일과 월·연간 비용, 해지 절감액을 관리하는 로컬 우선 웹 도구입니다.

## 핵심 기능

1. 서비스명·금액·결제 주기·갱신일을 검증해 구독 등록
2. 오늘·7일 이내·이후·해지 순으로 갱신 큐 자동 정렬
3. 월 환산 비용·연간 총액·해지 절감액 집계

## 설치 및 실행

Node.js 20 이상과 Python 3가 필요하며 런타임 의존성은 없습니다.

```bash
npm install --ignore-scripts
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 데이터는 해당 브라우저의 `localStorage`에만 저장됩니다.

## 사용 방법

- 결제 중인 구독의 서비스명, 분류, 금액, 결제 주기와 다음 갱신일을 등록합니다.
- 다가오는 결제 큐에서 오늘과 7일 이내 항목을 먼저 검토합니다.
- 더 이상 쓰지 않는 구독을 해지 상태로 바꾸면 활성 비용과 절감액이 즉시 갱신됩니다.

## 보안 및 제한사항

- 계정 ID, 비밀번호, 카드번호를 입력하거나 저장하지 않습니다.
- 외부 API, 분석 도구, 서버 데이터베이스를 사용하지 않습니다.
- 입력 길이·금액 범위·날짜·상태·결제 주기를 검증하고 표시 텍스트를 이스케이프합니다.
- 단일 브라우저 MVP이므로 데이터 백업, 알림, 은행 자동 연동은 지원하지 않습니다.
