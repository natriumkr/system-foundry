# GearLedger

소규모 스튜디오와 공유 작업실이 장비 대여, 반납기한, 상태와 보호해야 할 장비 가액을 관리하는 로컬 우선 업무 시스템입니다.

## 핵심 기능

1. 장비·대여자 별칭·가액·반납일을 검증해 대여 등록
2. 연체·오늘·임박·점검·반납 순으로 업무 큐 자동 정렬
3. 대여·점검·반납 장비 가액과 상태 추적

## 설치 및 실행

Node.js 20 이상과 Python 3가 필요하며 런타임 의존성은 없습니다.

```bash
npm install --ignore-scripts
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 데이터는 해당 브라우저의 `localStorage`에만 저장됩니다.

## 사용 방법

- 장비를 내보낼 때 장비명, 분류, 대여자 별칭, 가액, 반납 예정일을 등록합니다.
- 반납 큐에서 연체와 오늘 반납 항목부터 확인합니다.
- 돌아온 장비는 반납 완료로 바꾸고 정상·확인 필요·수리 필요 상태를 기록합니다.
- 점검이 필요한 장비는 점검 중으로 분리해 재대여를 방지합니다.

## 보안 및 제한사항

- 고객 실명과 연락처 대신 팀·프로젝트 별칭만 저장하도록 설계했습니다.
- 외부 API, 분석 도구, 서버 데이터베이스를 사용하지 않습니다.
- 입력 길이·가액 범위·날짜·상태를 검증하고 사용자 텍스트를 이스케이프합니다.
- 단일 브라우저 MVP이므로 바코드, 알림, 사진 증빙, 다중 사용자 동기화는 지원하지 않습니다.
