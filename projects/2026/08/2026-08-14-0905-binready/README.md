# BinReady

전자부품의 보관함 위치, 현재 수량, 다음 프로젝트 필요 수량을 관리하는 로컬 우선 개인 도구입니다.

## 대상 고객과 가격

- 대상: 전자공작·로봇 제작을 하는 학생, 취미 메이커, 개인 작업자
- 가격: 1회 구매 ₩9,900

## 핵심 기능

1. 부품 코드·분류·보관함·현재/필요 수량을 검증해 등록
2. 부품명·코드·보관함 통합 검색
3. 부족 수량 기반 프로젝트 준비 우선순위와 보충 기록

데이터는 브라우저 `localStorage`에만 저장되며 외부로 전송되지 않습니다.

## 설치·테스트·실행

Node.js 18 이상과 Python 3이 필요합니다.
외부 패키지가 없어 별도 의존성 설치는 필요하지 않습니다.

```bash
node --test tests/*.test.js
python3 -m http.server 4173 -d app
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## Docker

```bash
docker build -t binready .
docker run --rm -p 4173:4173 binready
```

## 보안 및 제한사항

- 보관함 이름에 개인정보나 출입 정보를 입력하지 마세요.
- 브라우저 데이터를 지우면 기록도 삭제됩니다.
- 여러 프로젝트별 BOM, 바코드 스캔, CSV 백업, 클라우드 동기화는 MVP에 포함하지 않습니다.
- 수량은 사용자가 직접 확인한 값을 기준으로 합니다.
