# ProofGuard

고객 시안의 승인 마감과 상태, 승인 전 제작 시 발생할 재작업 노출액을 관리하는 로컬 우선 업무 시스템입니다.

## 대상 고객과 가격

- 대상: 2~15인 소형 인쇄·간판·패키지 제작사
- 가격: 사업장당 월 ₩18,000

## 핵심 기능

1. 고객·작업·승인 마감·재작업 노출액을 검증해 등록
2. 마감 위험도 기반 승인 큐와 미승인 노출액 집계
3. 승인 대기·수정 요청·승인 완료 상태 추적

데이터는 브라우저 `localStorage`에만 저장되며 외부로 전송되지 않습니다.

## 설치·테스트·실행

Node.js 18 이상과 Python 3이 필요합니다.

```bash
npm install
npm test
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## Docker

```bash
docker build -t proofguard .
docker run --rm -p 4173:4173 proofguard
```

## 보안 및 제한사항

- 고객 개인정보, 결제정보, 비밀번호를 입력하지 마세요.
- 브라우저 데이터를 지우면 기록도 삭제됩니다.
- 파일 첨부, 전자서명, 고객 포털, 다중 사용자 감사 로그는 MVP에 포함하지 않습니다.
- 실제 제작 투입 전 서면 승인 원본을 별도로 보관해야 합니다.
