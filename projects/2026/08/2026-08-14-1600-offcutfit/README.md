# OffcutFit

자투리 판재의 규격·보관 위치·잔존 가치를 기록하고 새 작업과 적합 여부를 계산하는 로컬 우선 업무 시스템입니다.

## 대상 고객과 가격

- 대상: 소형 레이저 커팅·간판·목공·모형 제작소
- 가격: 사업장당 월 ₩19,000

## 핵심 기능

1. 소재·코드·규격·두께·보관 위치를 검증해 등록
2. 작업 규격과 직접/회전 배치 적합 여부 및 사용률 계산
3. 가용 면적·잔존 가치 집계와 사용 처리

외부 패키지가 없어 별도 설치가 필요하지 않습니다.

```bash
node --test tests/*.test.js
python3 -m http.server 4173 -d app
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## 보안 및 제한사항

- 위치명에 개인정보나 출입 코드를 입력하지 마세요.
- 실제 재단 전 소재 결함·재단 여유·장비 커프를 현장에서 확인하세요.
- 불규칙 형상, 결 방향, 자동 네스팅, 다중 부품 배치는 MVP에 포함하지 않습니다.
