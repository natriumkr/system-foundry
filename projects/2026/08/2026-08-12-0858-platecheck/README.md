# PlateCheck

3D 프린팅 부품의 출력판 적합성, 최적 0°/90° 방향, 한 판 최대 생산량을 계산하는 로컬 우선 도구입니다.

## 대상 고객과 가격

- 대상: 취미용 FDM 3D 프린터 사용자와 소형 메이커
- 가격: 1회 구매 ₩9,900

## 핵심 기능

1. 부품·출력판 치수와 간격 검증
2. 0°/90° 격자 배치 용량 비교
3. 필요 수량에 따른 출력판 수 계산

데이터는 브라우저 `localStorage`에만 저장됩니다.

## 설치·테스트·실행

Node.js 20 이상과 Python 3이 필요합니다.

```bash
npm install
npm test
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## Docker

```bash
docker build -t platecheck .
docker run --rm -p 4173:4173 platecheck
```

## 제한사항

- 직사각형 바운딩박스의 0°/90° 격자 배치만 계산합니다.
- 실제 출력 전 슬라이서에서 유효 영역, 브림, 서포트, 헤드 간섭을 확인해야 합니다.
- 복잡한 형상의 네스팅과 G-code 생성은 포함하지 않습니다.
