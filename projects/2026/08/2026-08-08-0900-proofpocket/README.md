# ProofPocket

구매품의 보증 만료일과 영수증·시리얼 보유 상태를 함께 관리하는 로컬 우선 개인 도구입니다.

## 핵심 기능

1. 구매일, 보증기간, 가격을 검증해 제품 등록
2. 만료일까지 남은 날짜와 보호 가치를 위험도순으로 표시
3. 영수증·시리얼 보유 여부를 눌러 청구 준비도 점검

## 실행

Node.js 20+와 Python 3가 필요합니다. 외부 API와 런타임 패키지는 없습니다.

```bash
npm install
npm test
npm start
```

브라우저에서 `http://localhost:8080`을 엽니다.

## Docker

```bash
docker build -t proofpocket .
docker run --rm -p 8080:8080 proofpocket
```

## 보안과 데이터

- 입력 길이, 허용 카테고리, 날짜, 보증기간, 금액 범위를 검증합니다.
- 사용자 입력은 HTML 표시 전에 이스케이프합니다.
- 실제 영수증 이미지나 시리얼 번호를 수집하지 않고 보유 여부만 저장합니다.
- 데이터는 현재 브라우저의 `localStorage`에만 저장됩니다.
- `.env`는 커밋하지 않으며 현재 비밀값은 필요하지 않습니다.

## 가격

1회 구매 ₩8,900. 첫 고객은 전자기기·3D 프린터 커뮤니티에 무료 데모와 보증 만료 체크 템플릿을 배포해 확보합니다.

## 제한사항

제조사별 실제 보증 약관을 자동 판정하지 않습니다. 표시된 만료일은 사용자가 입력한 기간으로 계산하므로 청구 전 구매처 또는 제조사의 약관을 확인해야 합니다.
