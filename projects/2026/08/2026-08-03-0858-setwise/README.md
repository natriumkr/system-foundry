# SetWise

음악 연습자가 공연 일정, 현재 자신감, 마지막 연습일을 기준으로 제한된 시간에 먼저 연습할 곡과 구간을 정하는 로컬 우선 개인 도구입니다.

## 핵심 기능

1. 곡명·집중 구간·자신감·권장 시간·공연일 검증 및 등록
2. 연습 공백·낮은 자신감·공연 임박도를 합산한 오늘의 우선순위 큐
3. 연습 완료 후 시간·자신감·최근 연습일 기록

## 설치 및 실행

Node.js 20 이상과 Python 3가 필요합니다. 런타임 의존성은 없습니다.

```bash
npm install --ignore-scripts
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 모든 데이터는 브라우저 `localStorage`에만 저장됩니다.

## 사용 방법

- 상단 슬라이더로 오늘 가능한 연습 시간을 설정합니다.
- 연습 큐는 자신감이 낮고 오래 쉬었거나 공연이 가까운 곡을 먼저 배치합니다.
- 한 곡이 남은 시간보다 길면 남은 시간만큼 짧은 세션으로 배정합니다.
- 세션을 마친 뒤 자신감을 선택하고 `연습 완료`를 누릅니다.

## 우선순위 계산

점수는 낮은 자신감, 최근 연습 이후 경과일, 공연까지 남은 기간을 합산합니다. 점수는 절대적인 실력 평가가 아니라 오늘의 순서를 정하는 로컬 휴리스틱입니다.

## 보안 및 개인정보

- 외부 API와 분석 도구를 사용하지 않습니다.
- 계정, 실명, 연락처를 수집하지 않습니다.
- 입력 길이·날짜·숫자 범위를 검증하고 화면 출력 시 HTML 특수문자를 이스케이프합니다.
- `.env`와 비밀키가 필요하지 않습니다.

## 가격 모델

- 1회 구매 ₩12,000
- 대상: 여러 곡을 동시에 준비하는 음악 전공생, 동아리·밴드 연주자, 취미 연주자

## 제한사항

단일 기기용 MVP입니다. 기기 간 동기화, 메트로놈, 악보 첨부, 교사 공유는 후속 버전 범위입니다.
