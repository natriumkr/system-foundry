# FocusQueue

마감일, 중요도, 예상 소요시간을 계산해 오늘의 학습 순서와 시간 예산 계획을 만드는 로컬 우선 웹 도구입니다.

## 대상 고객과 가격

- 대상: 과제와 시험 준비를 동시에 관리하는 학생 및 개인 학습자
- 가격: 1회 구매 ₩7,900

## 핵심 기능

1. 과목·할 일·마감·예상시간·중요도를 검증해 등록
2. 마감과 중요도 기반 우선순위 큐
3. 오늘 가능한 시간 안에서 자동 학습 계획 구성

데이터는 브라우저 `localStorage`에만 저장되며 외부로 전송되지 않습니다.

## 요구사항

- Node.js 20 이상
- Python 3

## 설치·테스트·실행

```bash
npm install
npm test
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 런타임 외부 패키지는 없습니다.

## Docker

```bash
docker build -t focusqueue .
docker run --rm -p 4173:4173 focusqueue
```

## 제한사항

- 우선순위 점수는 참고용이며 학교 일정, 휴식, 실제 난이도를 대신 판단하지 않습니다.
- 동기화·알림·교사 또는 보호자 계정 기능은 MVP에 포함하지 않습니다.
- 브라우저 데이터를 지우면 기록도 삭제됩니다.

## 테스트

Node.js 내장 테스트 러너로 입력 정제·범위 검증·긴급도·점수·시간 예산·상태 전환을 검사합니다.
