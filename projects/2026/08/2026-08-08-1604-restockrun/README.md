# RestockRun

소규모 인쇄·3D 프린팅·사진 스튜디오의 소모품 재고 런웨이와 재주문 예산을 관리하는 로컬 우선 업무 도구입니다.

## 핵심 기능

1. 현재 수량·일평균 사용량·재주문 기준·단가를 검증해 소모품 등록
2. 예상 사용 가능 일수에 따른 품절 위험 큐와 권장 주문 수량 계산
3. 사용 버튼으로 재고 차감 및 재주문 예산 즉시 갱신

## 실행

```bash
npm install
npm test
npm start
```

브라우저에서 `http://localhost:8080`을 엽니다. Node.js 20+와 Python 3가 필요하며 외부 API와 런타임 패키지는 없습니다.

## Docker

```bash
docker build -t restockrun .
docker run --rm -p 8080:8080 restockrun
```

## 보안과 제한사항

- 입력값 길이, 허용 카테고리, 음수, 0 사용량을 검증합니다.
- 사용자 입력은 HTML 출력 전에 이스케이프합니다.
- 데이터는 브라우저 localStorage에만 저장되며 비밀값은 필요하지 않습니다.
- 다중 사용자, 발주 전송, 공급사 가격 동기화는 제공하지 않습니다.

## 가격

사업장당 월 ₩16,000. 지역 출력소·메이커 스튜디오에 7일 무료 체험과 품절 위험 리포트를 제공해 첫 고객을 확보합니다.
