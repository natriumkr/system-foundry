# MarginMap

온라인 판매자를 위한 로컬 우선 단위경제성 계산기입니다. 플랫폼 수수료, 결제 수수료, 광고비, 배송비, 반품 기대비용, 월 고정비를 반영해 실제 주문당 이익과 목표 마진 판매가를 계산합니다.

## 핵심 기능

1. 실제 주문당 이익, 마진율, 예상 월 이익 계산
2. 손익분기 판매가와 목표 마진 판매가 역산
3. 분석 결과 CSV 내보내기

데이터는 브라우저 밖으로 전송되지 않으며 회원가입이나 API 키가 필요하지 않습니다.

## 요구사항

- Python 3.10 이상(정적 파일 서버용)
- Node.js 20 이상(자동 테스트용)

## 실행

```bash
python3 -m http.server 8080 -d app
```

브라우저에서 <http://localhost:8080>을 엽니다.

Docker를 사용한다면:

```bash
docker build -t marginmap .
docker run --rm -p 8080:8080 marginmap
```

## 테스트

외부 패키지 설치는 필요하지 않습니다.

```bash
npm test
```

## 계산 방식

- 비율 비용 = 판매가 × (플랫폼 + 결제 + 광고 + 세금 적립률)
- 반품 기대비용 = 반품률 × (출고 배송비 + 반품 처리비)
- 주문당 고정비 = 월 고정비 ÷ 월 주문량
- 실제 이익 = 판매가 - 모든 주문당 비용
- 목표 판매가는 비율 비용이 판매가와 함께 변하는 점을 반영해 대수적으로 역산합니다.

세금 적립률은 사용자가 보수적으로 정하는 현금흐름 준비값입니다. 실제 부가가치세와 소득세는 사업 형태와 매입세액 등에 따라 달라지므로 본 도구는 세무 자문을 대체하지 않습니다.
