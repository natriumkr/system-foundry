# SlotSignal

갑작스러운 예약 취소로 생긴 빈 시간대를 대기 고객과 연결하는 로컬 우선 업무 도구입니다. 서비스, 가능 시간대, 대기일, 슬롯 임박도를 점수화해 연락 순서를 제안합니다.

## 대상 고객

1~5인 미용실, 네일숍, 1인 클래스 등 예약 기반 소상공인입니다.

## 핵심 기능

1. 서비스·날짜·시간·예상 매출을 검증해 빈 슬롯 등록
2. 서비스와 가능 시간대를 포함한 대기 고객 관리
3. 적합도 기반 연락 큐와 예약 확정 처리

## 실행

Node.js 20+와 Python 3가 필요합니다. 외부 API나 런타임 패키지는 없습니다.

```bash
npm install
npm test
npm start
```

브라우저에서 `http://localhost:8080`을 엽니다. `npm start`는 `python3 -m http.server 8080 -d app`과 같습니다.

## Docker

```bash
docker build -t slotsignal .
docker run --rm -p 8080:8080 slotsignal
```

## 데이터와 보안

- 입력값의 길이, 허용 서비스, 날짜·시간, 금액 범위를 검증합니다.
- 사용자 입력을 HTML에 표시할 때 이스케이프합니다.
- 데이터는 브라우저 `localStorage`에만 저장됩니다.
- 실제 고객 데이터로 인터넷에 공개 배포하지 마세요. MVP에는 로그인, 동기화, 메시지 발송 기능이 없습니다.
- `.env`는 커밋하지 않으며 현재 MVP는 비밀값이 필요하지 않습니다.

## 수익 모델

사업장당 월 ₩15,000. 첫 고객은 지역 미용·네일 사업자 10곳에 7일 무료 체험과 취소 슬롯 회수액 리포트를 제안해 확보합니다.

## 제한사항

브라우저 단일 기기에서만 동작하며 자동 문자 발송, 실시간 다중 사용자, 예약 플랫폼 연동은 제공하지 않습니다. 연락 여부와 고객 동의는 사업자가 직접 확인해야 합니다.
