# QuoteLoop

소규모 B2B 서비스 사업자가 발송한 견적의 후속 연락일, 성사 가능성, 진행 금액을 관리하는 로컬 우선 업무 시스템입니다.

## 핵심 기능

1. 고객 별칭·서비스·금액·후속 연락일을 검증해 견적 등록
2. 지연·오늘·임박 순으로 후속 연락 큐 자동 정렬
3. 진행 총액·가중 파이프라인·성사 매출 집계와 상태 추적

## 설치 및 실행

Node.js 20 이상과 Python 3가 필요하며 런타임 의존성은 없습니다.

```bash
npm install --ignore-scripts
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 데이터는 해당 브라우저의 `localStorage`에만 저장됩니다.

## 사용 방법

- 견적을 발송한 직후 고객 별칭, 서비스, 금액, 성사 가능성, 후속 연락일을 등록합니다.
- 매일 후속 연락 큐의 지연·오늘 항목부터 처리합니다.
- 답변에 따라 작성 중, 발송, 후속 연락, 성사, 보류·실패 상태를 갱신합니다.
- 상단의 진행 총액과 가중 파이프라인으로 예상 매출 노출을 확인합니다.

## 보안과 개인정보

- 고객 실명·연락처 대신 별칭만 저장하도록 설계했습니다.
- 외부 API, 분석 도구, 서버 데이터베이스를 사용하지 않습니다.
- 입력 길이·금액 범위·날짜·상태·확률 값을 검증합니다.
- 사용자 입력은 HTML 특수문자를 이스케이프해 표시합니다.
- `.env`, API 키, 관리자 계정이 필요하지 않습니다.

## 가격 모델

- 사업장당 월 ₩17,000
- 대상: 사진·영상·디자인·청소·수리 등 소규모 B2B 서비스 사업자

## 제한사항

단일 브라우저 MVP입니다. 이메일 자동 발송, 고객 연락처 저장, 팀 계정, 회계·CRM 연동은 지원하지 않습니다. 가중 파이프라인은 사용자가 입력한 가능성을 기반으로 한 운영 지표이며 실제 매출을 보장하지 않습니다.
