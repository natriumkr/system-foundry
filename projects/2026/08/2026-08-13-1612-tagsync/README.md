# TagSync

진열 가격표와 POS 가격의 불일치, 영향 수량, 잠재 차액을 관리하는 로컬 우선 업무 시스템입니다.

## 대상 고객과 가격

- 대상: 독립 편의점·식료품점·생활용품점 등 소형 소매점
- 가격: 사업장당 월 ₩16,000

## 핵심 기능

1. 상품·SKU·진열가·POS 가격·영향 수량을 검증해 등록
2. 단가 차이와 잠재 차액 기반 수정 우선순위 큐
3. 가격표 수정 완료 상태 추적

데이터는 브라우저 `localStorage`에만 저장되며 외부로 전송되지 않습니다.

## 설치·테스트·실행

Node.js 18 이상과 Python 3이 필요합니다.

```bash
npm install
npm test
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다.

## Docker

```bash
docker build -t tagsync .
docker run --rm -p 4173:4173 tagsync
```

## 보안 및 제한사항

- 고객 개인정보·결제정보·비밀번호를 입력하지 마세요.
- 브라우저 데이터를 지우면 기록도 삭제됩니다.
- 바코드 스캔, POS 연동, 지점 동기화, 감사 로그는 MVP에 포함하지 않습니다.
- 실제 가격 수정은 매장의 승인 절차를 따르세요.
