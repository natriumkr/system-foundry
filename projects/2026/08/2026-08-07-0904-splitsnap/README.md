# SplitSnap

친구 여행과 소규모 모임에서 참가자별 공동 지출을 기록하면 개인별 잔액과 간단한 송금 목록을 계산하는 로컬 우선 정산 도구입니다.

## 핵심 기능

1. 중복을 검증하는 참가자 별칭 관리
2. 결제자와 분담자를 구분한 공동 지출 등록
3. 원 단위 오차 없는 잔액과 간소화된 송금안 생성

## 설치 및 실행

Node.js 20 이상과 Python 3가 필요하며 외부 런타임 의존성은 없습니다.

```bash
npm install --ignore-scripts
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 데이터는 해당 브라우저의 `localStorage`에만 저장됩니다.

## 사용 방법

- 모임 참가자를 별칭으로 추가합니다.
- 지출명, 금액, 결제자와 실제 분담자를 선택해 등록합니다.
- 하단의 송금 목록대로 보내면 모든 잔액이 정리됩니다.

## 보안 및 제한사항

- 실명, 계좌번호, 연락처, 카드정보를 요구하거나 저장하지 않습니다.
- 외부 API, 계정, 분석 도구와 서버 데이터베이스를 사용하지 않습니다.
- 입력값과 참가자 관계를 검증하고 화면 출력은 이스케이프합니다.
- 결제·송금 기능이나 외화 환율은 포함하지 않으며 계산 결과를 확인한 뒤 이용해야 합니다.
