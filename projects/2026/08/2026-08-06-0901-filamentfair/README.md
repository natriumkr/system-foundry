# FilamentFair

개인 3D 프린터 사용자가 필라멘트·전기·장비시간·실패 예비비를 포함한 실제 원가와 권장 가격을 계산하는 로컬 우선 도구입니다.

## 핵심 기능

1. 소재·사용량·출력시간·비용 변수를 검증해 작업 등록
2. 재료·전기·장비시간·실패 예비비 원가 자동 계산
3. 목표 마진 기반 권장 가격과 작업 상태 원장

## 설치 및 실행

Node.js 20 이상과 Python 3가 필요하며 런타임 의존성은 없습니다.

```bash
npm install --ignore-scripts
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. 데이터는 해당 브라우저의 `localStorage`에만 저장됩니다.

## 사용 방법

- 슬라이서에서 확인한 필라멘트 사용량과 출력시간을 입력합니다.
- 필라멘트 1kg 가격, 프린터 소비전력, 전기요금과 시간당 장비비를 조정합니다.
- 실패 예비율과 목표 마진을 넣어 실제 원가와 권장 가격을 확인합니다.
- 작업을 출력 완료 또는 실패 상태로 바꿔 계획 작업과 구분합니다.

## 보안 및 제한사항

- 외부 API, 분석 도구, 서버 데이터베이스와 계정이 필요하지 않습니다.
- 입력 범위와 상태를 검증하고 사용자 텍스트를 이스케이프합니다.
- 계산값은 입력한 소비전력과 비용 가정을 기반으로 하며 세금, 배송, 후가공, 지역별 법적 의무는 포함하지 않습니다.
- 3D 프린터는 제조사 안전지침에 따라 사용하고 작동 중 적절히 감독해야 합니다.
